# Data-Structure-Labs


This repository contains university-grade implementations of core data structures using object-oriented C++ architectures. Modules feature custom template patterns, strict attribute encapsulation, manual reference mapping with raw pointers, and runtime scope cleanups via class destructors.

## Structural Module Index

### Phase 1: Linear Arrays & Sequence Parsers
* **`01_string_processing.cpp`**
  * Controls text boundary loops, implements manual char parsing, and verifies string sequences.
* **`02_array_operations.cpp`**
  * Encapsulates basic mutation arrays, managing vector shifts during targeted data insertion and deletion parameters.
* **`03_linked_list.cpp`**
  * Manages dynamic dynamic-linked heap schemas via explicitly defined class constructors, pointer tracking, and memory destructor loops.

### Phase 2: Restricted Buffer Collections
* **`04_stack_implementation.cpp`**
  * Models a complete LIFO access buffer structure utilizing private variable boundaries and state tracking logic blocks.
* **`05_queue_implementation.cpp`**
  * Employs circular data parsing tracks to simulate real-time FIFO data stream management arrays.
    ### Phase 3: Hierarchical Class Graphs & Sorting Engines
* **`06_binary_search_tree.cpp`**
  * Tracks nested structured pointer elements, manages dynamic memory nodes on the system heap, and yields sorting passes via a recursive In-Order tree sweep.
* **`07_graph_representation.cpp`**
  * Establishes a flexible matrix graph using dynamic standard C++ vectors to model networked connection tables.
* **`08_sorting_and_searching.cpp`**
  * Features foundational Computer Science sorting operations (Selection Sort) alongside logarithmic search tracks (Binary Search).
